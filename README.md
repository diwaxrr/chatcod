## ✨ ¿Qué es ChatCod?

ChatCod es un asistente conversacional que **traduce ideas en aplicaciones web** sin necesidad de saber programar.

### 🎯 Para Usuarios Normales
- Describe lo que quieres → Obtén un sitio web funcional
- Conversación natural, paso a paso, sin jerga técnica
- Todo se ejecuta **localmente en tu computadora** (100% privado)

### 🏢 Para Fundaciones y PYMES
- Sistema para ayudar a **miles de pequeños negocios** a tener presencia web
- Micrositios gratuitos alojados en subdirectorios
- Impacto social real: **democratización digital**
